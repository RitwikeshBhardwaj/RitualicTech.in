# RitualicTech Landing Page

Marketing site for RitualicTech.in — an automation firm that makes business workflows run like a ritual.

## Theme
- Stone & olive (warm paper, deep green accent)
- Serif headlines, sans-serif body
- Clean, premium feel matching the "ritual" concept

## Layout
- One page, top to bottom
- Intro with promise, then six services, then industries, then CTA
- Form opens from buttons (not yet connected to backend)
